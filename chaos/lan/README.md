# Minimal real LAN progression: 1 / 5 / 10 / 25

No load is generated by this directory. It accepts evidence only from the
existing reviewed player/media tooling named in the private run plan. A real
one-player run lasts at least 10 minutes; only after its cleanup and manual
Wi-Fi recovery pass may the same explicit commit progress to 5, then 10, then
25 clients. Values above 25 are rejected.

`player-evidence.example.tsv` is the fail-closed composite contract produced by
`Import-BrowserObservation.ps1` from the reviewed Web JSON schemas. The exact
source bytes, their SHA-256 and every transformed field stay bound together;
guessed values and the untouched template are rejected.

Every level requires:

- exactly 1/5/10/25 requested and peak real MoQT sessions from one allowed
  client IP; authenticated viewers remain `not_measured` and are not claimed;
- numeric clock error with calibrated clocks;
- positive received media objects and bytes; level 1 additionally requires
  real presented frames, browser-observed RX-to-canvas p95 and an explicitly
  armed/lost/recovered Wi-Fi observation; `network_and_subscriber` remains
  `not_measured` because no real instrument exposes it, and
  `ingest_to_publish` remains `not_measured` until a hash-bound Gateway/server
  collector supplies it;
- client ICMP echo loss/jitter explicitly labelled as a network approximation,
  plus server/client CPU, memory, adapter bandwidth and duration;
- package SHA-256 and the approved-threshold set identifier;
- SHA-256-bound server/client collectors, raw browser observation and the
  Platform-converted composite player evidence, with provenance per field;
- exactly one Defender rule and one Hyper-V rule, then separately zero
  Defender, Hyper-V and process residue; and
- previous accepted evidence at 5/10/25 using the same local commit.

At level 1 `glass_to_glass` remains `not_available` unless Web measured it from
correlatable source timecode and clocks are calibrated. `not_measured`, `not_available`, `unavailable`, `simulated`
and numeric real values are distinct and are never converted to zero. At
levels 5/10/25, render-only fields are `not_available` because lightweight
sessions deliberately do not render.

Workflow:

```bash
cp chaos/lan/results.example.tsv /ABSOLUTE/PRIVATE/PATH/results-1.tsv
# Fill phase/player fields from their real APIs and copy collector fields and
# SHA-256 from the bounded server/client collectors; the untouched template fails.
chaos/lan/gate.sh --level 1 --results /ABSOLUTE/PRIVATE/PATH/results-1.tsv \
  --server-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-1/server-host-evidence.tsv \
  --client-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-1/client-host-evidence.tsv \
  --player-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-1/player-evidence.tsv
chaos/lan/gate.sh --level 5 --results /ABSOLUTE/PRIVATE/PATH/results-5.tsv \
  --server-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-5/server-host-evidence.tsv \
  --client-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-5/client-host-evidence.tsv \
  --player-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-5/player-evidence.tsv \
  --previous /ABSOLUTE/PRIVATE/PATH/results-1.tsv
chaos/lan/gate.sh --level 10 --results /ABSOLUTE/PRIVATE/PATH/results-10.tsv \
  --server-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-10/server-host-evidence.tsv \
  --client-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-10/client-host-evidence.tsv \
  --player-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-10/player-evidence.tsv \
  --previous /ABSOLUTE/PRIVATE/PATH/results-5.tsv
chaos/lan/gate.sh --level 25 --results /ABSOLUTE/PRIVATE/PATH/results-25.tsv \
  --server-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-25/server-host-evidence.tsv \
  --client-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-25/client-host-evidence.tsv \
  --player-evidence /ABSOLUTE/PRIVATE/EVIDENCE/lan-RUN/level-25/player-evidence.tsv \
  --previous /ABSOLUTE/PRIVATE/PATH/results-10.tsv
chaos/lan/render-report.sh --results /ABSOLUTE/PRIVATE/PATH/results-25.tsv \
  --output /ABSOLUTE/PRIVATE/PATH/report-25.md
```

Each evidence file must stay in that exact run/level export path and have an
adjacent `.sha256` sidecar naming the exact file. The gate rejects renamed,
manually moved, unbound or sidecar-less evidence.

Use `manual-wifi-recovery.md` at level 1. It requires a human to disconnect and
reconnect Wi-Fi through the Windows UI; no script changes the adapter, SSID,
airplane mode, route, firewall or other global networking.

These gates do not claim production capacity, HA, leak freedom, a latency SLO
or interoperability beyond the recorded machines, source, browser, Wi-Fi,
commit, load and duration. The current environment has not run any of them.
